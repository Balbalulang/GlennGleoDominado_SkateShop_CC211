# Skate Shop website

## Run it
1. Extract `skate-shop-website.zip`.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. An internet connection is needed for Bootstrap and Google Fonts CDNs.

## Files
- `index.html` — page structure and Bootstrap layout
- `style.css` — responsive dark skate-shop styling
- `script.js` — draggable category rail, mobile navigation, search, cart counter, and contact form
- `assets/` — the supplied images copied into the project

## Before publishing
- Replace `hello@skateshop.com` with the shop's real email in `index.html` and `script.js`.
- Update the sample product prices as needed.
- The contact form uses a `mailto:` link; connect a backend or form service if you want messages submitted without opening the visitor's email app.
- The cart is a front-end demo counter, not a checkout/payment system.
